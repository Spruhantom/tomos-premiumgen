# TomOS Premium Generator — retired

<blockquote>
**This project is retired.** TomOS SIP no longer has a Premium tier, subscription, activation code, licence file, device binding or feature-unlock system. The Android app now includes all features in one paid edition. Customers purchase the app through its selected sales channel; no licence generator is required.
</blockquote>

This repository is retained as historical source code only. Do not use it to issue licences for current TomOS SIP releases. No further releases or activation support are planned.

The app's commercial distribution and payment handling will be managed separately from its feature set. The app itself does not perform purchase verification or contact a licensing service.
